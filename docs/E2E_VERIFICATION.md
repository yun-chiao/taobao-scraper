# Listio 端對端驗證清單

> 目的：妳親手走一遍「賣家會做的事」，確認每一步的畫面與結果都符合預期。
> 每一列是 **操作 → 應該看到什麼**，右邊打勾。不符合的，記下流程編號＋步驟（例：`F3-4`）、實際看到什麼、最好附截圖。

## 準備

| | |
|:--|:--|
| 預覽網址 | 在 repo 根目錄執行 `python3 -m http.server 8765`，開 `http://localhost:8765/`（改版後先 `Ctrl/Cmd + Shift + R` 強制重新整理） |
| 畫面配置 | 左：模擬商品頁（上方三個分頁：淘寶耳釘 ¥58／天貓珍珠 ¥89／1688 抓夾 ¥12.5）；右：Listio 側邊欄 |
| 右上按鈕 | 「初次引導」「額度用完」「品牌與定價設定」「下載專案 (.zip)」 |
| 重置 | 預覽是記憶體狀態，**重新整理頁面就全部重來**（歷史預設有 2 筆：珍珠項鍊＝已帶入蝦皮、玳瑁抓夾＝未交付） |

> [!IMPORTANT]
> 預覽環境的兩個已知限制，**不是 bug**：
> 1. 右側側邊欄與「品牌與定價設定」是兩個獨立的模擬狀態，設定頁改了東西 **不會** 反映到側邊欄（真實擴充功能共用 `chrome.storage`，會即時同步）。
> 2. 模擬蝦皮頁一定填表成功，所以「填表失敗 → 自動複製到剪貼簿」的備援路徑只能在真實蝦皮後台驗證（見 F10）。

## F10 真實 Chrome 擴充功能（預覽做不到的）

**安裝（妳的筆電上做）**
1. `git clone` 這個 repo（或下載 zip 解壓）。
2. Chrome 網址列輸入 `chrome://extensions` → 右上開「開發人員模式」→「載入未封裝項目」→ 選 repo 裡的 **`extension/`** 資料夾（裡面有 `manifest.json`）。
3. 工具列把 Listio 釘選起來。之後更新程式：`git pull` 後回 `chrome://extensions` 按該卡片的 ↻。

> [!NOTE]
> `api.listio.app` 後端**尚未部署**，所以雲端模式第一次產生會失敗——F10-3 就是在驗這個失敗畫面是否友善。要測真實 AI 生成，請在 F10-4 前到「設定 → 方案與金鑰 → 自備 API Key」貼上妳的 [Google AI Studio](https://aistudio.google.com/apikey) 金鑰。

| 15 | 開兩個商品分頁來回切換 | 側邊欄首頁的「目前分頁」跟著切換；已產生過的那個顯示「開啟已產生的圖文」 | ☐ |

**出問題時怎麼抓資訊**：`chrome://extensions` → Listio 卡片 → 點「服務工作者」開 DevTools Console（紅字截圖給我）；側邊欄本身可按右鍵 →「檢查」看 Console。
